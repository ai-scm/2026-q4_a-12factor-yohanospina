# The Twelve Factor

## I. Codebase:
- Mantiene el codigo en un único repositorio, se puede acceder a el desde cualquier lugar permitiendo desplegar la misma base de código en entorno local o en servicios de prueba.
## II. Dependencies:
- Son todas las herramientas que el programa necesita para funcionar, especifica exactamente qué requiere la aplicación para correr.
## III. Config:
- Funciona principalmente para guardar contraseñas o codigo delicados que necesita una aplicación para funcionar que en caso de filtrarse podria comprometer los datos o información importante.
## IV. Backing Services:
- Son servicios externos que necesita la aplicacion para funcionar, como bases de datos en la nube.
